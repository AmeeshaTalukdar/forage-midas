

# Midas

A project repository developed as part of the **J.P. Morgan Chase Advanced Software Engineering Forage Program**, focusing on building practical software engineering skills in a real-world financial services context.

---

## 📌 Overview

This project simulates real-world engineering tasks commonly performed in financial institutions such as J.P. Morgan Chase. It focuses on applying software engineering principles to solve structured problems, improve code quality, and understand production-level workflows.

The goal of this repository is to demonstrate:

* Clean and maintainable code practices
* Problem-solving using structured programming approaches
* Understanding of software engineering workflows used in industry environments

---

## 🎯 Objectives

* Apply software engineering concepts in a simulated financial environment
* Develop solutions to structured programming tasks
* Strengthen understanding of industry development workflows
* Practice writing scalable and readable code

---

## 🧠 Key Learnings

Through this program, the following skills were developed:

* Writing modular and maintainable code
* Debugging and improving existing codebases
* Understanding real-world software engineering practices
* Working with structured problem statements and constraints
